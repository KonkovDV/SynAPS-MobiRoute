# Benchmark protocol

## Instances

Generated by `mobiroute generate` / `benchmark/generate_day.py` with fixed seed.
Modes: tiny, small, medium, large, `stress_200` (200 vehicles / 3200 requests),
wheelchair_heavy, medical_priority,
pooled_rides, disruption, infeasible, fairness_stress, peak_demand,
driver_unavailable, vehicle_breakdown, plus **ops_*** policy scripts
(`ops_clinic_peak` … `ops_shift_close`). Ops suite: `mobiroute ops-benchmark`.
SSOT write-up and measured seed-42 table:
[`docs/ops-cases-and-benchmark-2026-08-12.md`](ops-cases-and-benchmark-2026-08-12.md).
Ops results are `synthetic_benchmark` only. Greedy/FIFO never `OPTIMAL`.
Never label ops scripts as real Moscow trips.

## Algorithms to compare

FIFO, nearest-feasible, greedy insertion, CP-SAT tiny, ALNS (heuristic),
LBBD (future), rolling horizon (future), incremental repair (partial via
disruption recovery).

## Required artifacts per run

algorithm, seed, input_hash, config_hash, code version, SynAPS commit,
instance size, runtime, status, verified_feasibility, metrics, provenance,
claim_level.

## Forbidden

- Publishing one vanity KPI  
- Calling GREEDY/ALNS/RHC optimal  
- Labeling synthetic Moscow-zone data as real Moscow trips  
- Calling results customer validation without customer data
