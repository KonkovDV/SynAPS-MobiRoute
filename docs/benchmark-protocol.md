# Benchmark protocol

Rules every number in this repository follows.

1. **Pinned bytes.** Instances are vendored with SHA-256 sums; every result row
   records the digest of the file it solved, and a published reference applies
   only to those bytes.
2. **Independent verification.** Every plan, from any solver, is re-timed and
   re-priced by the verifier. A gap is quoted only for a verified plan that
   serves every order.
3. **Hierarchical references.** Where the reference ranks vehicles first
   (Solomon, Li & Lim, Sartori–Buriol), a distance gap is quoted only at the
   reference vehicle count; otherwise the vehicle difference is reported.
4. **Recorded conditions.** Seed, iteration budget or time limit, backend,
   Python version and platform are written next to the numbers.
5. **No optimality from heuristics.** `OPTIMAL` means a solver's proof on its
   own model (CP-SAT, SCIP, HiGHS), and the verifier still re-prices the plan.
6. **No filtering.** Failed or incomplete runs stay in the tables.
7. **Synthetic is labelled synthetic.** Generated days have no reference;
   they are compared solver against solver.
8. **Seeds and tests for method comparisons.** A change to the search is
   judged on several seeds per instance and paired runs, with the
   Wilcoxon signed-rank test; one seed is one draw.
9. **Two algebras on Cordeau.** The paratransit kernel uses operator rules
   (integer minutes, curb dwell, alighting slack) and is never compared with the
   literature; the claim gate in `benchmarks/academic.py` blocks such a gap.
   The rich-VRP engine and `benchmarks/cordeau_exact.py` use the published
   algebra and are compared.
