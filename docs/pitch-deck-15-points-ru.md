# Питчдек — 15 обязательных разделов (RU)

1. **Logo** — SynAPS-MobiRoute (текстовый знак до визуала).  
2. **Project name** — SynAPS-MobiRoute.  
3. **Short description** — открытое объяснимое ядро планирования accessible DARP.  
4. **Readiness stage** — инженерный прототип; synthetic benchmark; без customer validation.  
5. **Industry** — социальный / доступный транспорт, paratransit, NEMT-adjacent.  
6. **Technologies** — Python, Pydantic, OR-Tools CP-SAT, JSON Schema, deterministic hashing.  
7. **Intellectual property** — MIT open-source kernel; customer data remains customer.  
8. **Product image** — схема: intake → MobiRoute → plan/diff/reason codes → dispatcher.  
9. **Problem solved** — назначение ТС, маршруты, окна, коляски, перепланирование, объяснимый отказ.  
10. **Implementation benefit** — прозрачность отказов, воспроизводимость, fairness-отчёт, снижение ручного хаоса (гипотеза пилота).  
11. **Business model** — on-prem license + integration + support + analytics.  
12. **TAM/SAM/SOM** — bottom-up: операторы соцперевозок / DRT / NEMT; SAM — РФ и дружественные рынки с on-prem; SOM — 1 город, 1 парк, 1 контракт. Без выдуманной выручки.  
13. **Competitors** — Ecolane, TripSpark, Trapeze, RideCo, RU stacks, «По пути» (смежный); MobiRoute = kernel, не full suite.  
14. **Team** — OR + transport planning + software (уточнить ФИО в финальной версии).  
15. **Pilot / investment request** — shadow-пилот с оператором; трекерское сопровождение гипотез KPI.
