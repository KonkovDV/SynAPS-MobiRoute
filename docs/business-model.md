# Business model (bottom-up, no invented revenue)

**Date:** 2026-08-12. Scenario model only — not audited market sizing.

## TAM (conceptual universe)

- Municipal / regional social transport operators  
- Paratransit and NEMT-like services  
- Demand-responsive accessible fleets  
- Large social-protection institutions with own transport  

Count operators from public registries during pilot scoping — do not invent totals.

## SAM

- Russian and friendly markets needing **on-premise / protected** optimization  
- Operators with own fleet, mixed individual + group trips  
- Organizations that already have CAD/AVL or booking and need a better kernel  

## SOM (near-term)

- One city  
- One fleet / depot cluster  
- One dispatch contour  
- One integration contract  
- Shadow mode before live recommend  

## Monetization (potential)

1. On-premise optimization kernel license  
2. Integration with existing dispatch  
3. Constraint / priority configuration services  
4. Paid support  
5. Analytics module  
6. Online dispatch module  
7. White-label for regional operators  

## Pilot KPIs (measure before claiming lift)

service rate, medical on-time, wait/ride mean+P95, reasoned rejects, deadhead,
utilization, manual overrides, fairness multi-metric, plan churn, plan runtime,
accessibility violations = 0.

**Do not promise percentage improvements before baseline comparison.**
