# Мотивационное письмо (черновик) — 10-й поток Академии инноваторов

**Вопрос экспертов (FAQ i.moscow, 2026-08-12):** «Почему именно мы должны пройти в акселератор?»  
**Дедлайн потока:** 14 сентября 2026.

Проект важен, потому что доступные перевозки — критическая социальная услуга,
где отказ без причины и непрозрачный перенос бьют по уязвимым группам. Команда
способна реализовать ядро, опираясь на уже проверенную дисциплину
детерминированного планирования SynAPS и академический контур DARP 2024–2026.

Ближайший план: не «внедрить социальное такси Москвы», а довести
объяснимый контур до shadow-пилота. На синтетике уже закодированы правила
оператора (06:00–19:00, ожидание ≤ 60 мин, два сопровождающих, WAV, группа,
паллиативный канал) и мировые аналоги (next-day ADA, subscription 50% как
метка, не как закон РФ). Это материал для трекера, не отчёт о KPI города.

Нужен трекер, чтобы проверить гипотезы на контакте с оператором: какие
ограничения реально жёсткие, какой churn допустим, как встроить reason codes
в регламент диспетчера. Встречи с трекером не пропускаем. Пилот — shadow mode
на обезличенных данных одного парка, с помощью Академии в запуске пилотов
с городскими структурами. Масштабирование — через on-prem интеграции
региональных операторов.

За время сопровождения ожидаем: воспроизводимый протокол пилота, согласованные
KPI, первую теневую оценку fairness и service rate — **без** заявления о
«уже улучшенном социальном такси Москвы». Один проект: только MobiRoute.
