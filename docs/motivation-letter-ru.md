# Мотивационное письмо (черновик)

Проект важен, потому что доступные перевозки — критическая социальная услуга,
где отказ без причины и непрозрачный перенос бьют по уязвимым группам. Команда
способна реализовать ядро, опираясь на уже проверенную дисциплину
детерминированного планирования SynAPS и академический контур DARP 2024–2026.

Нужен трекер, чтобы проверить гипотезы на контакте с оператором: какие
ограничения реально жёсткие, какой churn допустим, как встроить reason codes
в регламент диспетчера. Пилот — shadow mode на обезличенных данных одного
парка. Масштабирование — через on-prem интеграции региональных операторов.
За время сопровождения ожидаем: воспроизводимый протокол пилота, согласованные
KPI, первую теневую оценку fairness и service rate — **без** заявления о
«уже улучшенном социальном такси Москвы».
